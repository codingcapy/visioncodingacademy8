# Vision Coding Academy Website

Modern, responsive website for Vision Coding Academy built with React, Tailwind CSS, and Framer Motion.

## Features

- Elegant coding-themed design
- Responsive navigation with terminal-style animations
- Interactive course catalog
- Dynamic gallery showcase
- Contact form with ReCAPTCHA integration
- Location maps integration
- Multi-language support (English / Korean)

## Locations

- West Vancouver: 2428 Haywood Ave, West Vancouver, BC V7V 1Y1
- Coquitlam: 2885 Barnet Hwy, Coquitlam, BC V3B 1C1

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- React Router
- Axios
